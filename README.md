# SMART UNLOCK — UI Demo

Developed by **𝙳𝙰𝚁𝙺𝚆𝙴𝙱.𝙾𝚁𝙶**

A responsive front-end website demo for a device service console. Includes a dashboard, IMEI format/checksum validation, simulated activity logs, toast notifications, demo history, and copy actions.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For clipboard paste/copy support, run it through a local web server (for example, VS Code Live Server).

## Important
This project is a front-end demonstration only. It does not connect to M-KOPA, carrier systems, manufacturers, or unlock APIs. It does not unlock phones or change device state. All request logs, counters, and result panels are demo UI behavior. A real service requires a legitimate provider API and authorization.
